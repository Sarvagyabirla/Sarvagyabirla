<h2 align="center">⚡ Aeris AI Assistant</h2>

<p align="center">
<b>Local-First Cognitive Desktop Assistant for Windows</b>
</p>

Aeris is an AI desktop assistant designed to **understand requests, reason about them, interact with tools, and safely perform actions on Windows**.

### ✨ Current Capabilities

- 🎙️ Voice interaction
- 🗣️ Wake-word control
- 🧠 Gemini-powered reasoning
- ⚡ Offline command routing
- 👁️ Screen understanding
- 💻 Windows automation
- 📁 Controlled filesystem operations
- 🧑‍💻 AI coding workspace
- 🌐 Browser & web actions
- 📧 Gmail integration
- 📦 Windows package operations
- 🔐 Permission-controlled execution
- 🔊 Local text-to-speech
- 🖥️ Animated sci-fi HUD
- 📊 System telemetry
- 🛡️ Safe tool execution architecture

### 🧠 Design Philosophy

Aeris separates:

`Understanding`

↓

`Planning`

↓

`Permission`

↓

`Execution`

This reduces the risk of unrestricted AI-generated system actions.

### 🧰 Core Direction

`Python` `Gemini AI` `Voice AI` `Automation`  
`Windows` `Tool Integration` `Local-First AI`
